Canadian breadth · Nordic restraint

Five controls. One clear northern voice.

Icy Beauty is a focused polyphonic synthesizer algorithm for the Expert Sleepers disting NT. It moves from warm and woody to bright, grainy, and glass-like without changing engines or hiding controls.

Factory sound

Eight voices. Four disconnected gate-group control sets. Tone, Motion, Grain, and Resonance at 50%. Release at 65%. MIDI Omni to Output 1.

The algorithm, simply

Every note follows the same path. The controls change its colour, movement, texture, ring, and fade.

Three tone layers A rounded main note, a quiet octave, and a high interval.
Tone Balances the layers and sets brightness.
Motion + Grain Add slow drift and fine irregular texture.
Resonance Adds a tuned glass-like ring.
Release Shapes the final fade into a ±5 V output.

Sound parameters

These five normal host parameters are the complete sound surface. Each can also be mapped to CV in the disting NT.

Default 50%

Tone

Dark and rounded at the bottom; brighter and more layered at the top.

Default 50%

Motion

Slow independent pitch movement on each voice, up to about ±13 cents.

Default 50%

Grain

Fine random pitch variation and noise, from clean to weathered.

Default 50%

Resonance

Moves from a dry note to a clear tuned, glass-like ring.

Default 65%

Release

Sets the fade after note-off, from about 80 ms to 12 seconds.

Setup and routing

Choose the voice and gate-group counts when adding the algorithm. Everything else appears as a normal parameter.

Parameter Default What it controls
Voices 8 One to sixteen shared MIDI/CV voices.
Gate groups 4 Zero to six independent CV/gate control sets.
MIDI channel Omni Every channel, or one selected channel from 1–16.
Semitones 0 Transposes every MIDI and CV voice from −11 to +11 semitones.
Octaves 0 Transposes every MIDI and CV voice from −4 to +4 octaves.
Output Output 1 The destination bus.
Output mode Add Adds to the bus; Replace overwrites it.

Every Gate input starts at None and every CV Count starts at 0, so a fresh instance is MIDI-only until CV control is explicitly connected.

MIDI control

The performance mappings are fixed, useful, and ready without a setup page.

Control Response
VelocityLevel, with a small brightness change.
Pitch bendFixed ±2-semitone range.
Mod wheelRaises Motion.
Sustain pedalHolds released notes until pedal-up.
Poly aftertouchRaises Resonance and adds a little Motion per note.
Channel pressureApplies that pressure response across the chord.
Stop / panicStop, Reset, CC 120, and CC 123 clear every MIDI and CV voice.

CV and gate control

Up to six independent gate groups can play adjacent 1 V/octave pitch buses. All groups are disconnected by default.

Adjacent routing

  • Gate input N chooses the group’s gate bus.
  • Gate N CV count reserves 0–11 voices.
  • Pitch buses are gate +1, +2, and onward.
  • Input 9 with Count 2 uses pitches on Inputs 10 and 11.

Gate and sample & hold

  • Gate rises above 1.0 V and falls below 0.5 V.
  • S&H Off tracks pitch while the gate is high.
  • S&H On samples pitch at each rising edge.
  • 0 V is C3; every added volt raises pitch one octave.

Counts reserve fixed voice partitions in group order; MIDI uses only the unreserved voices, so MIDI and CV never steal from one another. A Count increase under a held gate waits for the next rising edge, while a decrease releases the removed voices. Retriggers during an audible release tail resume smoothly. After Stop or panic, a held CV gate must go low and rise again before restarting.

Install the prebuilt plug-in

No compiler or development toolchain is needed.

Three steps

  1. Download icy_beauty-plugin.zip from Releases.
  2. Unzip it at the root of the disting NT SD card.
  3. Rescan plug-ins and add Icy Beauty.
